📁 This week: File Collaboration

Tip of the Day

Stop emailing files. Start working on the same one.

Word · Excel · PowerPoint

Real-time co-authoring — no more v3_FINAL_revised.docx

Any Office file saved in SharePoint or OneDrive can be edited by multiple people at the same time. You'll see each person's colored cursor live, and changes sync instantly. Open the file from Teams or SharePoint instead of your desktop and everyone's working on the same copy.

Loop Components

Paste a live checklist into Teams, Outlook, or Word

In a Teams chat, type "/" and choose Loop components — or use the Loop app — to insert a table, checklist, or bullet list that stays live wherever it's pasted. Edit it in the chat and it updates in the email too. Perfect for shared action item lists that everyone can check off.

SharePoint · Version History

Restore any previous version of a file in one click

SharePoint silently keeps a full version history for every document. Right-click any file → Version history to see who changed what and when. Click Restore next to any version to bring it back instantly. Your "oops, I overwrote the wrong section" safety net is always on.

SharePoint · Alerts

Get notified the moment a key document changes

In SharePoint, select any file and choose Alert Me (under the three-dot menu) to receive an email or Teams notification whenever someone edits it. Set it to "Anything changes" for contracts or policies you need to track. No more wondering if the form got updated.

SharePoint · OneDrive

Put an expiration date on every external link you share

When sharing a file externally, click "Link settings" and set an expiration date. The link auto-disables after that date — no need to remember to revoke it later. Good practice for anything shared outside the organization, especially temporary document requests.

Teams · File Sharing

@ a file in Teams to share it with context — no URLs

In any Teams message, type @ and switch to the Files tab to search your SharePoint or OneDrive files by name. Teams embeds a rich preview card with a direct link — no digging for URLs, no confusion about which version. The recipient can open or co-edit it right from the message.
